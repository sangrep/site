# Sangrep brand assets

This directory contains the first-party, web-ready Sangrep mark, lockups,
favicon, and tiles approved for this website.

Do not edit SVGs by hand, recolor the resolved teal bar, or create unreviewed
variants. Each asset's SHA-256 digest, provenance class, and license are in
[`provenance.json`](provenance.json). The application icon is an exact copy
of `sangrep-favicon.svg`, enforced by the media check.

Example:

```html
<img src="/brand/sangrep-lockup.svg" alt="Sangrep" />
```
