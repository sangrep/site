# Component origin

This repository begins with a clean, website-specific history. Its first
implementation combines an established Sangrep landing-page design with
approved first-party brand assets, then adapts both to a standalone public
website boundary.

The public history intentionally contains only website source, public
governance, licensing, provenance classifications, checks, and deployment
guidance. It does not reproduce unrelated product implementation or internal
delivery history.

Every designated brand asset has a destination-relative digest and license
classification in
[`public/brand/provenance.json`](public/brand/provenance.json).
