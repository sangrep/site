# Security policy

Do not report a vulnerability in a public Issue, pull request, Discussion,
commit, test fixture, or preview comment.

Use [GitHub private vulnerability reporting](https://github.com/sangrep/site/security/advisories/new).
If that channel is unavailable, email security@sangrep.com with the repository
name, affected public URL or commit, impact, and a minimal reproduction.

Do not include live credentials, private documents, raw provider payloads,
local databases, customer material, or unrelated system diagnostics. Rotate
any credential that was exposed before sending the report.

The maintained security surface is the current default-branch website and its
active deployment. This statement does not establish a Sangrep application
release, product support window, format support, entitlement, or service-level
commitment.
