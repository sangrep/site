# Governance

Maintainers own website scope, public information, privacy, security,
accessibility, licensing, brand, deployment, and release decisions.

One maintainer approval and the required repository check are the minimum
merge gate. Security, privacy, license, brand, legal-copy, deployment, and
public-visibility changes may require additional review. Production
publication also requires the gates in
[`docs/deployment.md`](docs/deployment.md).

Public history is permanent. Maintainers remove private context and
unsupported claims before a branch, Issue, pull request, review, workflow log,
artifact, preview, release, or deployment is created.
